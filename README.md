# Nour Salem — Backend Software Engineer Portfolio

> **"I architect backend systems that scale beyond demos."**

A modern, high-performance developer portfolio built for **Nour Salem**, Backend Software Engineer specializing in distributed architectures, message queue processing, high-throughput APIs, and cloud microservices.

---

## 🌟 Key Features

- **Editorial Warm Dusk Visual Design**: Handcrafted dark warm theme inspired by high-end design systems featuring golden bokeh ambient lighting, custom SVG framing, and zero horizontal overflow.
- **Interactive Project Architecture Explorer**: Deep-dive modals for each project displaying problem statements, target microservice architectures, empirical performance metrics (e.g. 5,000+ ops/sec throughput, <15ms latency), and GitHub source links.
- **Embedded Resume / CV PDF Viewer**: Seamless modal preview with immediate direct download of the official `Nour_Salem_CV.pdf`.
- **Responsive Mobile-First Ergonomics**: Tailored layouts for all viewports with fluid typography and optimized touch points.
- **Interactive Tech Stack Grid**: Comprehensive breakdown of core backend languages, microservices, databases, ORMs, message brokers, and DevOps tooling.
- **Session-Based Preloader**: Sleek loading screen with progress percentage counter running once per user session.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or pnpm / yarn

### Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/Noursalem2005/portofolio_nour.git

# Navigate into project folder
cd portofolio_nour

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

---

## 📦 Deployment on Vercel

This portfolio is optimized for 1-click deployment on Vercel:

1. Push your code to GitHub.
2. Import the `portofolio_nour` repository into Vercel.
3. Keep default settings (`Framework Preset: Next.js`).
4. Click **Deploy**.
